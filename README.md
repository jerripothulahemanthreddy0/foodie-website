# 🍔 Foodie Website

A responsive food ordering website built using HTML, CSS, and JavaScript. Users can explore food products, view prices, add items to their cart, and manage quantities.

## 🚀 Features

- Browse food products
- Display product names and prices
- Add food items to cart
- Increase and decrease product quantities
- Calculate total price
- Display total cart quantity
- Dynamic cart updates using JavaScript

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- JSON
